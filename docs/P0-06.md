# P0-06 Compiler + n8n Adapter

## Implementation Summary

P0-06 adds a platform-neutral compiler and workflow-engine boundary. A validated
P0-05 `ExecutionIR` can be compiled deterministically to n8n Workflow JSON, then
validated, imported inactive, published, executed, and queried through the
`WorkflowEnginePort` contract.

## Port Design

- `WorkflowCompilerPort`: `ExecutionIR -> CompiledWorkflow`.
- `WorkflowEnginePort`: validate/import/publish/execute/get execution.
- Frozen generic DTOs carry workflow hashes, references, validation evidence,
  and execution facts without exposing n8n types to Domain/Application.
- Every mutating engine operation requires an explicit idempotency key.

## Adapter Design

- `N8nWorkflowCompilerAdapter` owns all n8n node types, connection layout,
  webhook configuration, retry mapping, runtime placeholders, and Credential
  Ref mapping.
- `N8nWorkflowEngineAdapter` maps the generic Port to the existing versioned
  gateway contract.
- Fake compiler/engine adapters provide deterministic contract and application
  tests without a live n8n instance.

## Supported Compiler Mapping

| IR node | n8n mapping |
|---|---|
| `invoke_agent` | HTTP Request with frozen endpoint/Credential Ref and same-Attempt retry |
| `join` | Merge with stable dependency input indexes |
| `end` | No Operation terminal node |

The design baseline does not define executable parameters for `decision`,
`wait`, `evaluate`, Artifact, or Checkpoint nodes. These nodes fail compilation
with `N8N-NODE-001` rather than receiving invented behavior.

## Database Changes

None. P0-06 uses the existing immutable Workflow Version and IR hash model.

## Verification

Run `bash scripts/check-p0-06.sh` with `P0_06_POSTGRES_DSN` and optionally
`P0_06_PYTHON_BIN`. The gate runs all P0-01 through P0-05 checks first and then
the compiler and adapter contract suite.

Final verification passed under Python 3.10 and PostgreSQL 16: offline lint
(116 files), offline type gate (25 files), 57 discovered tests with two expected
database skips followed by P0-02 7/7, P0-03 7/7, P0-04 10/10, P0-05 12/12,
and P0-06 9/9. Ruff and Mypy were unavailable; the deterministic offline gates
passed. `git diff --check` also passed.

## Remaining Risks

- The authoritative n8n version, import/publish API, node templates, Credential
  Ref resolver, and external status vocabulary remain TBD-04/TBD-10.
- Contract tests validate the existing gateway mapping; a live-n8n conformance
  test remains required when the production API is fixed.
- S0-S4 gate ownership is P0-07. This task provides `publish_workflow` but does
  not expose a new route or bypass the publication gate.
