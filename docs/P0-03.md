# P0-03 Domain State Machines

P0-03 provides explicit Workflow Version, Execution, and Node transition
matrices. Callers use `StateTransitionService`; PostgreSQL locks the aggregate,
validates the transition in Domain code, updates state, and appends history in
one transaction.

Migration `0002_state_machines` preserves Workflow Version structural
immutability while allowing only the specified lifecycle transitions. It also
adds database guards for Execution and Node transitions and an aggregate-history
index. Illegal and duplicate transitions raise a domain error and are logged;
terminal states cannot be reopened.

Run the complete gate with Python 3.10 and an isolated PostgreSQL test database:

```bash
P0_03_PYTHON_BIN=/path/to/python3.10 \
P0_03_POSTGRES_DSN='postgresql://user:password@host/database' \
bash scripts/check-p0-03.sh
```
