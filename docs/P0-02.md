# P0-02 PostgreSQL Control Plane

The P0-02 control-plane adapter is optional at process startup so the existing
SQLite v1/v2 compatibility path remains runnable. Configure
`ORCHESTRATOR_POSTGRES_DSN` to enable PostgreSQL facts and run:

```bash
python scripts/migrate-postgres.py up
python scripts/migrate-postgres.py down
```

Install the declared runtime dependency in connected development environments:

```bash
python -m pip install -e .
```

The offline Python 3.10 image uses the pinned `psycopg2-binary` wheel under
`orchestrator/vendor/python`. The migration creates an isolated schema, records
and verifies checksums, runs transactionally, and supports rolling back the
latest migration. Credentials must be supplied by the deployment secret
mechanism or a secure libpq credential source; they must not be committed to
`.env` files.

Redis settings are present for deployment wiring only. P0-02 does not import a
Redis SDK and Redis is not used as a source of record.
